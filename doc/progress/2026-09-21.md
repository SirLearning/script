## 2026-09-21 — How the PopDep grids are defined

- TIGER genomic grid: one row per base on each of 45 RefSeq v1 arm segments (`getRefV1ChrLength`); `chromosomeLength.txt` is `Chr Length nTaxa`; `PopDepCrossChr` + samtools depth, MAPQ 0, taxa order `interleave`. ntaxa500 uses the N500 taxaBamMap so nTaxa=500.
- Density-filter histogram (separate): 250×150 cells on RelativeDepth_Mean × RelativeDepth_SD in `[0,5)×[0,5)`; trusted cells = densest 60%/80% of non-empty cells.
