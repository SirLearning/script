- Question: can vmap4 `main_raw` VCFs feed [SINGER](https://github.com/popgenmethods/SINGER) to sample an ancestral recombination graph (ARG; user wrote AGR).
- Checked `chr000.vcf.gz` (320G; 8285 samples). VCFv4.1, `GT:AD:GL`, unphased `0/0` / `0/1` / `./.`, mixed ploidy prefixes, multi-allelic and indel ALT (`I`/`D`).
- SINGER requires **phased**, high-quality genomes; sites with missing GT are dropped; multi-allelic and SVs are excluded. Official target is hundreds of diploid haplotypes, 1–5 Mb windows, uncompressed `.vcf` prefix (not `.vcf.gz`).
- Conclusion: **do not run SINGER on the current VCF as-is**. Need a same-ploidy subset, biallelic SNP filter, missingness/imputation, phasing, then a small-region pilot.
